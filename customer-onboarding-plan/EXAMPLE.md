# Customer onboarding plan: an invented example

*Illustrative example with invented data.* The companies, the people, the dates and the notes below are all invented. The seller is an invented 30-person company that sells time-tracking and invoicing software to small design and architecture studios. Its new customer, Customer K, is an invented 18-person architecture studio. First come the four inputs the customer success lead supplied, in full, then the plan the workflow template returned. This is a first run, so there is no status update yet.

### 2. Our facts (written once by the customer success lead)

```
What we sell: time-tracking and invoicing software for small design and
  architecture studios.
Usual onboarding steps:
  1. The customer's admin creates the logins and sets roles. (Onboarding
     specialist)
  2. Import clients, projects and billing rates. (Onboarding specialist)
  3. Import past timesheets, when bought. (Onboarding specialist)
  4. Each user logs their first days of time. (Onboarding specialist)
  5. Set up the invoice template. (Onboarding specialist)
  6. The person who invoices drafts invoices for a period already worked
     and checks each total against the timesheet report. (Onboarding
     specialist)
  7. First live invoice run. (Onboarding specialist)
  8. Project budget reports. (Customer success lead)
  9. Mobile app for site visits. (Onboarding specialist)
First real use, for a studio: the person who invoices produces a real
  billing run's invoices from tracked hours, in the studio's own account,
  without our help, and checks each total against the timesheet report
  before anything is sent.
Support and sessions: as the order form states. We do not restate them.
Words we never use with customers: "guarantee".
```
